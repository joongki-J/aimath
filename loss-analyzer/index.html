손실함수 분석기

y = ax와 y = ax + b 추세선을 선택해 L(a) 또는 L(a,b)를 구합니다

🌿 사용 방법 — how to use
✏️
직접 입력
모형을 y=ax 또는 y=ax+b 중에서 고른 뒤, x, y 칸에 숫자를 입력하세요. 입력 후 방향키로 셀을 이동할 수 있습니다.
📋
엑셀 붙여넣기
엑셀에서 x, y 두 열을 복사한 뒤, 표 밖 빈 공간을 클릭하고 Ctrl+V를 누르면 데이터가 자동으로 채워집니다.
🔽
드래그 채우기
셀에 마우스를 올리면 우하단에 ● 핸들이 나타납니다. 아래로 드래그하면 숫자가 1씩 증가하며 자동 채워집니다.
🍃
수식 복사
계산 후 식 옆 📋 복사 버튼을 클릭하면 분수계수 일반형 수식이 클립보드에 저장됩니다.
🌱 데이터 입력 시트 — data sheet
추세선 모형 선택
# x y
🌾 L(a) 결과 — result
🍂 데이터를 입력하고 계산 버튼을 눌러주세요
